# 部署指南 · Deploy Guide

域名：**https://game.wuqingbao.com**
构建产物：`game-wuqingbao-com/site/dist/`（纯静态，零运行时）

## 1. 一次构建（在本机 / CI 上都一样）

```bash
cd game-wuqingbao-com/site

# Astro 会自动读取 .env.production（PUBLIC_SITE 已填好 game.wuqingbao.com）
# Umami 统计按需填入 .env.production，空值=不注入统计脚本
npm run build

# 产物在 dist/
ls dist/index.html dist/llms.txt dist/sitemap.xml dist/robots.txt
```

根目录也提供了快捷入口：

```bash
cd game-wuqingbao-com
npm run build
```

### 构建后本地预览（用于上线前最后一轮检查）

```bash
cd site
npm run preview          # 默认 http://localhost:4321
```

## 2. 部署

任选一种纯静态托管即可：

| 平台 | 上传目录 | 备注 |
|---|---|---|
| **Nginx / Caddy** | 把 `site/dist/*` 扔到站点根（如 `/var/www/game.wuqingbao.com/`） | 见下面的 nginx 片段 |
| **Vercel / Netlify / Cloudflare Pages** | Build command: `cd site && npm run build`, Output: `site/dist` | 平台的 Environment Variables 里设置 `PUBLIC_SITE=https://game.wuqingbao.com`（覆盖本地 .env.production），并按需填 Umami |
| **OSS + CDN**（阿里 OSS / 腾讯 COS / AWS S3） | 上传 `dist/` 到 bucket，CDN 回源 | 缓存策略见第 3 节 |

### Nginx 最简片段

```nginx
server {
  listen 443 ssl http2;
  server_name game.wuqingbao.com;
  root /var/www/game.wuqingbao.com;
  index index.html;

  # 游戏 iframe 里可能会 POST/PUT 状态，放行即可；
  # 真正纯静态文件 GET/HEAD 足够
  location / {
    try_files $uri $uri/index.html $uri.html =404;
  }
}
```

## 3. 缓存策略（重要）

按路径分桶，避免游戏本体加载慢的同时 SEO/GEO 内容能即时刷新：

```
/robots.txt, /sitemap.xml, /llms.txt     → no-cache（秒读）
/*.html (页面)                            → no-cache 或 max-age=60
/assets/*, /styles.css                    → max-age=31536000 immutable（带 hash）
/covers/*, /vendor/*                      → max-age=86400（一天）
/vendor/sandboxels/*, /vendor/hexgl/*     → 体积大（>15MB），max-age=604800 并开 brotli 更好
```

## 4. 域名 / TLS 侧

- DNS：`game.wuqingbao.com` 的 A/CNAME 指到托管机器/平台
- 必须开 HTTPS（canonical / og:image / Twitter 都写死了 `https://` 前缀）
- 部署后用 https://game.wuqingbao.com/llms.txt 与 https://game.wuqingbao.com/sitemap.xml 快速冒烟
- 提交 sitemap：Google Search Console / Bing Webmaster，AI 引用引擎则会自己抓 robots + llms.txt

## 5. 体积参考（v1）

```
dist/ 总大小:  ~120 MB
├── /vendor/   30 款游戏自托管   ~105 MB
├── /covers/   30 张封面截图     ~3.6 MB
├── /assets/   Astro 打包 JS CSS ~200 KB
├── llms.txt                        ~25 KB
├── sitemap.xml                     ~25 KB
└── 92 页 HTML                    合计几 MB
```

> `dist/vendor/` 与 `dist/covers/` 来自本地构建时的 `site/public/`（不在 Git 里），部署机器构建或 CI 构建时都必须已存在。如果改在 CI 上构建，请把 `site/public/vendor/` 与 `site/public/covers/` 作为 CI 的 artifacts 上传或用 LFS 管理。

## 6. Umami（可选）

.ev.production 默认留空，未启用。启用步骤：

1. 在 Umami（Cloud 或自托管，如 `https://stats.game.wuqingbao.com`）创建站点
2. 把 `SCRIPT 地址` 和 `WEBSITE ID` 填进 site/.env.production：
   ```
   PUBLIC_UMAMI_SRC=https://stats.game.wuqingbao.com/script.js
   PUBLIC_UMAMI_ID=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
   ```
3. 重新 `npm run build`，所有页面会带 `<script defer src=... data-website-id=...>`

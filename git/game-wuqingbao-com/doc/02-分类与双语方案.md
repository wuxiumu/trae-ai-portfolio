一个游戏可属多类（数组），首页展示分类 chip 按游戏数量排序。

## 标签体系（辅助，非强制）

受控词表分 4 组，每款游戏可挂 0-5 个标签：

- **玩法 genre**：`tetris-like` `snake` `flappy-like` `breakout` `invaders` `match-3` `merge` `chess` `mahjong` `platformer` `runner` `racing` `physics` ...
- **输入 input**：`keyboard` `mouse` `touch` `gamepad`
- **风格 style**：`pixel-art` `minimalist` `neon` `hand-drawn`
- **难度 difficulty**：`pick-up-5s` `brainy` `hardcore`

## 双语方案

采用 **URL 前缀式**：

- 默认英文，无前缀：`/`、`/games/2048`、`/categories/puzzle`
- 中文加前缀：`/zh/`、`/zh/games/2048`、`/zh/categories/puzzle`
- 每个页面双向 `hreflang` 交叉标注，搜索引擎正确关联
- 顶栏「中文 / English」按钮做同页语种切换

### 文案来源

| 内容 | 存储位置 | 语言 |
|---|---|---|
| UI 字典 | `site/src/i18n/index.js` | 中英各一份 |
| 分类名 + 描述 | `site/src/data/taxonomy.js` | `{en, zh}` |
| 游戏标题/简介/玩法 | `site/src/games/<slug>.json` | `{en, zh}` 各字段 |

中文简介暂缺时前端显示 `🈶 中文待补` 徽标，不阻塞上架。

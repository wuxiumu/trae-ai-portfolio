# 05 · 游戏管理流程

## 加一款新游戏（标准 3 步）

### Step 1 — 加种子

在 `site/seeds.json` 数组末尾追加一条：
```json
{
  "slug": "新游戏简写",
  "repo": "owner/repo",
  "branch": "master",
  "title_en": "English Title",
  "title_zh": "中文标题",
  "summary_en": "one-liner",
  "summary_zh": "一句话中文",
  "howto_en": "controls",
  "howto_zh": "操作方式",
  "categories": ["puzzle"],
  "tags": ["keyboard", "merge"],
  "stars_hint": 1000,
  "license_hint": "MIT",
  "priority": 1
}
```

同时在 `games-list.md` 表格加一行。

### Step 2 — 跑脚本

```bash
# 只处理这一条
node scripts/fetch-games.mjs --only=新游戏简写

# 或批量 clone 后手工集成
bash scripts/clone-all.sh 新游戏简写
```

脚本自动完成：下载 → License 检查 → 探测入口 → 拷贝到 `site/public/vendor/` → 生成 `src/games/<slug>.json`。

### Step 3 — 验收

```bash
cd site && npm run dev
# 打开 http://localhost:4321/games/新游戏简写
```

确认：iframe 能玩 / 中文简介合适 / 分类正确 / 标签对。

## 种子字段说明

| 字段 | 必填 | 说明 |
|---|---|---|
| slug | ✅ | kebab-case 唯一标识，用作目录名和 URL |
| repo | ✅ | GitHub owner/name |
| branch | 推荐 | 默认 main，不对会按候选顺序试 |
| title_en | ✅ | 英文标题 |
| title_zh | 推荐 | 中文标题（留空则回退英文） |
| summary_en | ✅ | 一句话简介，卡片上显示 |
| summary_zh | 推荐 | 中文简介 |
| categories | ✅ | 从 9 大类里选 1-3 个 id |
| tags | 推荐 | 标签数组 |
| priority | 推荐 | 1=首批精选 2=第二批 3=长尾 |
| featured | 可选 | true = 首页推荐展示 |
| hint_path | 可选 | 入口不在根目录时指定 |

## fetch-games.mjs CLI

```
node scripts/fetch-games.mjs [选项]

--limit=N             本轮最多处理 N 条
--only=slug1,slug2    指定 slug
--priority=N          只处理 priority ≤ N
--dry-run             只打印不写文件
--update              已抓过的重新拉
--allow-build         需要 npm build 的也跑（默认跳过）
--no-strict-license   LICENSE 缺失时用 README 兜底
--seeds=custom.json   指定其他种子文件
```

## clone-all.sh CLI

```
bash scripts/clone-all.sh [选项] [slug1 slug2 ...]

--dry-run     只打印不执行
--all         强制重新 clone
--update      已存在的 git pull
```

## run-batch.sh 分批推进

```
bash scripts/run-batch.sh 1          # 跑第 1 批（priority=1, limit=30）
bash scripts/run-batch.sh status     # 查看各分类游戏数
```

## games-list.md 格式

```markdown
| 标题 | 简写 | 分类 | 体积 | git项目链接 | 已clone |
|---|---|---|---|---|---|
| 吃豆人 | pacman | 街机/动作 | ~200KB-1MB | https://github.com/mumuy/pacman | ✅ |
```

`clone-all.sh` 读第 2 列（简写）和第 5 列（链接）。
`已clone` 列每次跑完后手动更新或用 `--status` 自动回填。

## 失败处理

| 状态 | 原因 | 处理 |
|---|---|---|
| download 404 | 仓库改名/删除/网络超时 | 确认 repo 名，更新 seeds.json |
| license: UNKNOWN | LICENSE 文件缺失 | 去上游确认授权或移除 |
| entry: no index.html | 源码需 build | 标记 `needs-build`，本地 build 后手工拷 |
| 体积过大 | > 50MB | 走外链模式，不拷入 public/vendor |

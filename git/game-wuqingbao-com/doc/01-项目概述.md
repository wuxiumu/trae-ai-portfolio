# 01 · 项目概述

## 是什么

一个中英双语的开源 H5 小游戏网站（game.wuqingbao.com），从 GitHub 筛选轻量级纯前端游戏，iframe 嵌入或外链试玩，本地静态托管。

## 目标

- 收录 100+ 款开源 H5 小游戏，分类清晰，点开即玩
- 中英双语 SEO 友好（每语言独立 URL、hreflang 交叉）
- 纯静态，部署到 GitHub Pages / Cloudflare Pages 即可上线
- 后期发展自研小游戏，站点作为承载平台

## 策略：第三方 → 自研

| 阶段 | 内容 | 时间 |
|---|---|---|
| **第一阶段** | 接入第三方开源游戏（iframe/外链），快速铺量做内容 | 当前 |
| **第二阶段** | 基于开源项目二次改造（换皮、加关卡、调 UI） | 内容稳定后 |
| **第三阶段** | 自研原创小游戏，用 Phaser/PixiJS 开发，站点首发 | 长期 |

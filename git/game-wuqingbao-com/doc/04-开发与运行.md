# 04 · 开发与运行

## 环境要求

- **Node 18+**（推荐 20/22/26）
- git、curl、tar（macOS/Linux 自带）

本机默认 node 版本低时用：
```bash
export PATH="/usr/local/opt/node@26/bin:$PATH"
```

## 本地开发

```bash
cd site
npm install          # 首次安装依赖
npm run dev          # → http://localhost:4321（热更新）
```

## 构建

```bash
cd site
npm run build        # 产物 → site/dist/
npm run preview      # 本地 serve dist/ 验证
```

## 部署

`site/dist/` 是纯静态产物，扔到任何地方即可：

- **Cloudflare Pages**：根目录指向 `site`，构建命令 `npm run build`，输出目录 `dist`
- **GitHub Pages**：`npm run build` 后把 `dist/` 内容推到 `gh-pages` 分支
- **Vercel / Netlify**：框架选 Astro，一键导入

## 批量 clone 游戏源码

```bash
bash scripts/clone-all.sh              # 全量 clone
bash scripts/clone-all.sh pacman hex   # 只 clone 指定的
bash scripts/clone-all.sh --dry-run    # 预览
bash scripts/clone-all.sh --update     # 已存在的 git pull
```

clone 产物在 `vendors/<slug>/`，不提交 git。

## 抓取 + 集成到站点

```bash
# 方式 A：通过 fetch-games.mjs（读 seeds.json，自动下载+校验+拷站）
node scripts/fetch-games.mjs --only=hextris

# 方式 B：手工
# 1. vendors/pacman/ 里找到 index.html
# 2. 把整个目录复制到 site/public/vendor/pacman/
# 3. 编辑 site/src/games/pacman.json 把 fetched 改 true，entry 填路径
```

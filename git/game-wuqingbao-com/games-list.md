## 集成分批规划

| 批次 | 范围 | 数量 | 动作 |
|---|---|---|---|
| **B2-R 恢复** | 已标记 fetched 的 9 款（2048/pacman/js-tetris/hextris/invaderz/css-sweeper/snake-io/spaceinvaders/adarkroom） | 9 | `site/public/vendor/` 当前为空、iframe 全部 404。重跑 `node scripts/fetch-games.mjs --only=<上述9款> --update` 恢复运行时文件 |
| **B2a 直拷** | 其余 🟢 静态可玩且 <10MB（#1-13,15,18,20,24,25,29-32） | 19 | 同一脚本自动探测 entry 直拷；retrogames 需手动做合集入口页，snake/devilglitches/duckhunt/onslaught/penpa 用 `hint_path` 指定子目录 |
| **B2b 构建** | 🔨 需构建（#14,16,17,19,22,23,28） | 7 | `npm i && npm run build` 后拷产物，或 `fetch-games.mjs --allow-build`；逐款验证 |
| **B2c 大型** | >10MB（#33,34,35） | 3 | adarkroom/hexgl 直拷（注意仓库体积）；sandboxels 62MB 超 50MB 硬阈值 → 删 `lang/` 多语言包裁剪，仍超则走外链模式 |
| **暂缓** | 🖥 需服务端（#21,26,27） | 3 | 等 Node/Python server 容器化部署方案，源码保留 |
| **B3 内容** | 全部已集成游戏 | - | 补中英简介核对 + 封面截图 480×270 |
